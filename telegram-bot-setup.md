# Настройка Telegram Bot для ToDo Mini App

## 1. Создание бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Выберите имя бота (например: "ToDo Mini App")
4. Выберите username бота (например: "todo_miniapp_bot")
5. Сохраните полученный токен

## 2. Настройка Mini App

1. Отправьте @BotFather команду `/newapp`
2. Выберите созданного бота
3. Введите название приложения: "ToDo"
4. Введите описание: "Простой и удобный планировщик задач"
5. Загрузите иконку 512x512px
6. Введите URL вашего приложения: `https://your-domain.com/todo.html`
7. Выберите платформы: Web

## 3. Команды бота

Настройте команды через @BotFather командой `/setcommands`:

```
start - Открыть ToDo приложение
help - Помощь по использованию
stats - Показать статистику задач
```

## 4. Описание бота

Установите описание командой `/setdescription`:

```
🗂 Простой и удобный планировщик задач

✅ Создавайте и управляйте задачами
📱 Работает прямо в Telegram
☁️ Синхронизация между устройствами
📊 Отслеживание прогресса

Нажмите "Открыть приложение" или используйте /start
```

## 5. Пример кода бота (Node.js)

```javascript
const { Telegraf } = require('telegraf');

const bot = new Telegraf('YOUR_BOT_TOKEN');

// Команда start - открывает Mini App
bot.command('start', (ctx) => {
  ctx.reply('Добро пожаловать в ToDo! 📝', {
    reply_markup: {
      inline_keyboard: [[
        {
          text: '📱 Открыть приложение',
          web_app: { url: 'https://your-domain.com/todo.html' }
        }
      ]]
    }
  });
});

// Команда help
bot.command('help', (ctx) => {
  ctx.reply(`
🗂 <b>ToDo Mini App - Помощь</b>

<b>Основные функции:</b>
✅ Создание задач
✏️ Редактирование задач
🗑 Удаление задач
📊 Фильтры (все/активные/выполненные)
📤 Поделиться прогрессом

<b>Команды бота:</b>
/start - Открыть приложение
/stats - Статистика задач
/help - Эта справка

<b>Как использовать:</b>
1. Нажмите "Открыть приложение"
2. Добавьте свои задачи
3. Отмечайте выполненные
4. Делитесь прогрессом с друзьями!
  `, { parse_mode: 'HTML' });
});

// Команда stats (пример)
bot.command('stats', (ctx) => {
  // Здесь можно получить статистику из базы данных
  ctx.reply(`
📊 <b>Ваша статистика:</b>

📝 Всего задач: 12
✅ Выполнено: 8
⏳ Активных: 4
📈 Прогресс: 67%

Отличная работа! 💪
  `, { 
    parse_mode: 'HTML',
    reply_markup: {
      inline_keyboard: [[
        {
          text: '📱 Открыть приложение',
          web_app: { url: 'https://your-domain.com/todo.html' }
        }
      ]]
    }
  });
});

bot.launch();
```

## 6. Деплой

1. **Статичный хостинг**: GitHub Pages, Netlify, Vercel
2. **HTTPS обязательно**: Telegram требует HTTPS для Mini Apps
3. **Домен**: можно использовать поддомен или собственный домен

## 7. Тестирование

1. Отправьте боту команду `/start`
2. Нажмите кнопку "Открыть приложение"
3. Проверьте работу всех функций
4. Протестируйте на разных устройствах

## 8. Дополнительные возможности

- **Cloud Storage**: хранение данных в облаке Telegram
- **Haptic Feedback**: тактильная обратная связь
- **Theme Support**: поддержка тем Telegram
- **Main Button**: основная кнопка внизу экрана
- **Back Button**: кнопка назад в заголовке

## 9. Безопасность

- Валидация данных от Telegram WebApp
- Проверка подписи initData
- Ограничение доступа по пользователям (если нужно)
